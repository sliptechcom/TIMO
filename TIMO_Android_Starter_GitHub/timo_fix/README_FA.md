# TIMO Android Starter

نسخه اصلاح‌شده پروژه TIMO.

## تغییر مهم
Gradle Wrapper تنظیم شده و پروژه از Gradle 8.9 استفاده می‌کند که با Android Gradle Plugin 8.7.3 سازگار است.

## باز کردن پروژه
1. Android Studio را ببندید.
2. این ZIP را استخراج کنید.
3. Android Studio > Open را بزنید.
4. پوشه `TIMO_Android_Starter_Fixed` را انتخاب کنید.
5. اجازه بدهید Gradle Sync کامل شود.

اگر Android Studio پیغام دانلود Gradle داد، اجازه دانلود بدهید؛ حجم Gradle حدود 130MB است.

بعد از Sync موفق، مرحله بعد اتصال S24 Ultra و نصب برنامه است.
